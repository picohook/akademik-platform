## Dependency audit

The release build and `npm audit --omit=dev` reported **one high** advisory package
(`@xmldom/xmldom`, transitive) and **one moderate** advisory package (`epubjs`).
The audit's suggested dependency change is a major epub.js upgrade and needs
separate compatibility validation. Dependency versions in this pinned release
match the tested `fc0645c` lockfile.

### Follow-up: production dependency audit now clean

The server never imports `epubjs`; the browser uses the pinned
`spike/app/public/vendor/epubjs/epub.min.js`. `epubjs` was moved to
`devDependencies`, so the production Docker image (`npm ci --omit=dev`) no longer
installs `epubjs` or its `@xmldom/xmldom` tree.

```text
npm audit --omit=dev  -> 0 vulnerabilities
npm audit             -> 2 dev-only advisories (epubjs/xmldom)
```

A future v104 release image must be built after this package change. The
existing v103 image remains pinned and unchanged; this is a provenance note, not
a retroactive claim about the deployed artifact.
