## Scope and verification

P0 was approved by the product owner under **social watermarking + access
control**. The download action and new v118 offline saves receive identity
stamps. Original `/file` and `/book.epub` reader streams remain session/grant
protected and technically saveable, including when `allow_download=false`.
Legacy offline copies, screenshots/photos, watermark removal and traceability
of every copy are outside the accepted guarantee. No copy-prevention guarantee
is made. See [accepted scope and predeployment evidence](../V118-PREDEPLOY-2026-10-23.md).

The image was built from a **Git archive of the approved application pin**;
the mutable working tree was not used as its build context. Thirteen image
files match the archive; they match the browser-tested files after LF/CRLF
normalization. Nine public resources match the archive byte for byte through
HTTPS. `/api/config` returns version **118**, the full pinned SHA and
`production`; `/api/health` returns **200 / DB**. Only the web service was
recreated. DB and Caddy container IDs stayed unchanged.

Fresh migrations created both ticket tables with **enabled and forced RLS**;
the lasting tenant policy marker and grant trigger were verified. Ordered
timestamps and outputs are retained in the evidence below.

The six live browser scenarios used unique, temporary generated PDF/EPUB books:

1. Actual ticketed PDF download, HTTP 200, identity/date stamp verified.
2. Actual ticketed EPUB download, HTTP 200, identity/date stamp verified.
3. PDF catalog offline button → native IndexedDB Blob; SHA-256 matches the
   delivered POST body, provenance recorded without ticket persistence.
4. Equivalent EPUB offline save and hash/stamp verification.
5. **Eleventh ticket-issuance attempt** → HTTP **429** / `Retry-After`, visible
   wait message, existing IndexedDB IDs and hashes unchanged. Four issued
   tickets served the actual full/offline downloads; six more were issued
   before the rejected eleventh attempt. This is not a claim of eleven complete
   file transfers.
6. SW v9 shell ready → network offline → hard reload → PDF text layer and EPUB
   iframe both rendered original text and identity stamps.

`--ignore-certificate-errors` for this local Caddy certificate, including its
Service Worker. Separate Node HTTPS smoke and source checks validated the
