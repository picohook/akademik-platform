# v133 — CSP `style-src` `blob:` (2026-10-27)

## Sorun

EPUB okuyucuda **yayıncı CSS'i ve kendi tema/boyut override'ımız uygulanmıyordu.**
Konsolda CSP ihlali dışında hata yok — sessiz bozulma.

## Kök neden — doğrulanmış

`server.mjs` uygulama kabuğuna şu politikayı gönderiyordu:

```
style-src 'self' 'unsafe-inline'          ← blob: YOK
```

1. `spike/app/public/epub-engine.mjs:495-500` → `rendition.themes.register()` +
   `.select()` + `.fontSize()`. Tema/font boyutu epub.js'in tema sisteminden geçer.
2. `vendor/epubjs/epub.min.js` → `_()` = `new Blob([css], {type:'text/css'})`,
   ardından `createObjectURL`. epub.js stil sayfasını **`blob:` URL** olarak
   `<link>` ile enjekte eder.
3. `epub-engine.mjs:111` → `allowScriptedContent: false`; epub.js bu durumda
   iframe'i **yalnızca** `sandbox="allow-same-origin"` ile kurar
   (`epub.min.js`: `this.iframe.sandbox="allow-same-origin"`).
4. Sandbox'lı iframe **kendi politikasını almaz, üst belgenin CSP'sini devralır**.
   Dolayısıyla üst belgedeki `style-src` bu iframe'de de geçerliydi ve `blob:`
   olmadığı için tema stil sayfası **her chapter'da** düşüyordu.

Yani düzeltme kozmetik değil: okuyucunun tema ve yazı boyutu işlevi fiilen
çalışmıyordu.

## Değişiklik

CSP tek kaynağa taşındı: **`spike/app/security-headers.mjs`** (`APP_CSP`).
`server.mjs` artık `res.setHeader('content-security-policy', APP_CSP)` diyor.
Amaç: politikanın test edilebilir olması — `server.mjs` import edildiğinde sunucu
başlattığı için (yan etkili modül) doğrudan test edilemiyordu.

Tek fark:

```diff
- style-src 'self' 'unsafe-inline';
+ style-src 'self' 'unsafe-inline' blob:;
```

**Bilinçli olarak DEĞİŞTİRİLMEYEN:**

- `script-src 'self'` — chapter belgeleri `allow-same-origin` ile koşuyor ama
  script yok; `blob:`/`unsafe-eval` eklemek yayıncı içeriğine kod çalıştırma
  yolu açardı. Okuyucunun kopyalama/highlight politikası da buna dayanıyor.
- `object-src 'none'`, `base-uri 'self'`, `frame-ancestors 'none'`,
  `form-action 'self'`, `connect-src 'self'` — aynı kaldı.
- `img-src`/`worker-src`/`frame-src` zaten `blob:` içeriyordu (kapak görselleri,
  worker'lar); onlara dokunulmadı.

## Doğrulama — yerel, ölçülen

```
$ node test/security-headers.test.mjs
ok 1 - style-src allows blob: so the EPUB theme stylesheet is not blocked
ok 2 - script-src stays script-free of blob: and unsafe-eval
ok 3 - core hardening directives are unchanged
# pass 3   # fail 0
```

**Negatif kontrol** (testin gerçekten bir şey yakaladığının kanıtı): `blob:`
geçici olarak çıkarıldığında **`# fail 1`**, geri konulduğunda **`# pass 3`**.

Gerçek sunucudan header (`PORT=3917 node server.mjs`, `GET /`):

```
status=200
CSP=default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline' blob:;
    img-src 'self' data: blob:; font-src 'self' data:; connect-src 'self';
    frame-src 'self' blob: data:; worker-src 'self' blob:; object-src 'none';
    base-uri 'self'; form-action 'self'; frame-ancestors 'none'
```

Komşu test bozulmadı: `test/epub-copy-policy.test.mjs` → **7/7 pass**.
